# track_data
**Feature-tracking datasets produced by [HRCM](https://hrcm.ceda.ac.uk).**

Tracked phenomena include tropical cyclones, extratropical cyclones, smaller-scale cyclones (e.g., polar lows, medicanes) and mesoscale convective systems, and these datasets have been produced with peer-reviewed feature-tracking algorithms, particularly *TRACK* (Hodges et al., 1994; Hodges et al., 1995; Hodges et al., 2017), *TempestExtremes* (Ullrich et al., 2017; Ullrich et al., 2021), *PyFLEXTRKR* (Feng et al., 2023), and *SyCLOPS* (Han and Ullrich, 2025).

If you identify any data issues, such as missing files or corrupt or malformatted data, please raise an issue.

This repo is a work in progress; please bear with us...
